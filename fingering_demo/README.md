# 乐器指法动画演示工具（教学示意）

用自制手部骨架与简化笛管模型，根据指法片段驱动手指关节，让指定指腹接近对应孔位。
**本项目仅用于视觉教学示意：几何上的指腹–孔位接触不等于真实演奏正确。** 真实演奏还涉及
气息、口风、音色、按孔气密性与肌肉控制，这些都不在本模型范围内。

## 模型与约定

- `skeleton.py`：四指简化手 + 6 自由度手腕。每个关节的旋转轴与活动范围都在**该关节的局部
  坐标系**定义；屈曲为局部 `+y`，外展为局部 `+z`。前向运动学只做刚体旋转/平移的复合，
  因此骨长是模型常量，求解器无法拉伸骨骼。
- `flute.py`：沿世界 Y 轴的简化圆管，6 个音孔沿管轴排列；孔 1..4 为四指本位孔，孔 0/5 为
  相邻孔切换的拉伸孔。
- `ik.py`：带优先级的阻尼最小二乘（Levenberg–Marquardt）逆解。腕部正则只约束 6 个腕部
  自由度且权重很弱；接触任务（P1）优先于悬停任务（P2）。目标不可达时保留可见残差，
  绝不通过拉长手指伪造贴合，并报告超限（设计上为 0）。
- `timeline.py` / `animation.py`：指法片段与时间线。过渡窗口内目标位置与开合权重用
  smoothstep 平滑混合，接触的建立与解除连续。每个姿态都从**固定的半屈曲初值**独立求解，
  所以 `pose_at(t)` 是时间的纯函数——任意时间跳转都得到确定姿态，与播放历史无关。
- `render.py` / `ui.py`：侧视（抬/按）与顶视（指列展开）双视图；可拖动时间与过渡滑块、
  播放、点选并拖动目标孔位、观察骨架、导出数据。
- `export.py`：导出**真实关节变量曲线**（弧度/米）与带优先级和接触状态的接触标记 CSV。
- `measurement.py` / `offscreen.py`：离屏测量接触距离、关节超限与骨长守恒，并出图出报告。

## 运行

```bash
pip install -r requirements.txt

# 交互界面（需要图形环境；无显示环境会自动回退 Agg）
python -m fingering.ui

# 离屏：测量报告 + 关节曲线 + 接触标记 + 关键帧 PNG
python -m fingering.offscreen --out output

# 测试
python -m pytest tests/ -q
```

## 输出含义

- `joint_curves.csv`：每个采样时刻全部 22 个关节变量 + 腕部位姿 + 关节超限量。
- `contact_markers.csv`：每指每时刻的目标、指腹位置、距离、优先级（1=接触/2=悬停）
  与状态（`contact` / `hover` / `*_missed`）。
- `measurements.txt`：不同手型比例与相邻孔连续切换下的最大/平均接触残差、超限与骨长漂移。
